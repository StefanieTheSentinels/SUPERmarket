# SUPERmarket

A small project that combines **data exploration in Jupyter notebooks** with a **lightweight documentation site** (MkDocs). The repository is structured to keep the analysis work in `src/` and publishable docs configured via `mkdocs.yml`. :contentReference[oaicite:0]{index=0}

## What’s inside

- `src/` — project source materials (notebooks / analysis work). 
- `mkdocs.yml` — MkDocs configuration for generating a documentation site.
- `requirements.txt` — Python dependencies for running the notebooks and docs locally.
